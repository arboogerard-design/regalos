De PDF a Markdown con MarkItDown (regalo de «comenta PDF»)

MarkItDown es una utilidad Python de Microsoft que convierte documentos a Markdown, conservando estructura como títulos, listas y tablas. Tiene licencia MIT. Soporta PDF, Word y Excel, entre otros formatos.

Repositorio: https://github.com/microsoft/markitdown

Frase para pegar en Claude Code

Consulta https://github.com/microsoft/markitdown y su README. Crea un entorno virtual .venv en esta carpeta e instala MarkItDown con las dependencias pdf, docx y xlsx usando python -m pip install "markitdown[pdf,docx,xlsx]" dentro de ese entorno. Convierte mi archivo documento.pdf a documento.md con markitdown documento.pdf -o documento.md. Comprueba el resultado y dime si falta contenido. No sobrescribas el PDF original.

Necesitas Python compatible (consulta la versión requerida en el README actual). Claude Code puede solicitar permisos de instalación.

Uso en Windows PowerShell

python -m venv .venv
.\.venv\Scripts\python.exe -m pip install "markitdown[pdf,docx,xlsx]"
.\.venv\Scripts\markitdown.exe documento.pdf -o documento.md

Adjunta el Markdown o pide a Claude Code que lea documento.md. Revisa tablas y contenido antes de usarlo. La conversión básica no garantiza extraer el texto de escaneos ni preservar gráficos o maquetación. Para interpretar diseño o imágenes conserva el PDF. No hay un porcentaje universal de ahorro de tokens.
